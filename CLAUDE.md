# Idioma

Cuando te comuniques en español en este proyecto (chat con el usuario, mensajes de
commit, texto de UI, comentarios en código, lo que sea), usa siempre español neutral
con conjugación de "tú" (tú tienes, tú puedes, tú quieres). Nunca uses voseo
rioplatense ("vos tenés", "vos podés", "querés", "probá", "elegí" como imperativo,
etc.) — el usuario no es argentino y esto ya se corrigió varias veces.
